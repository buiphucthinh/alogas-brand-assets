# Alogas brand assets

Public, read-only artwork for the Alogas Zalo Mini App, served through jsDelivr:

    https://cdn.jsdelivr.net/gh/buiphucthinh/alogas-brand-assets@v1/banners/v1/category/<category>/<NN>.webp

- `banners/v1/category/{gas,stove,water,accessories}`: 152 approved category banners, 1080×1080 WebP q82. `manifest.json` lists each file and the original it came from.
- Tag `v1` is frozen. Never overwrite a file under a published tag: add `banners/v2/` and a new tag instead.
